## Overview

Neuronotes unifies multi-dimensional latent ability estimation (θ ∈ ℝ⁵⁸), ontological prerequisite constraints, distractor-level semantic misconception tracking, and adaptive intervention routing for Inorganic Chemistry (JEE Advanced level).

### Key Capabilities

| Capability | Module | Description |
|:---|:---|:---|
| **CC-MIRT** | `cc_mirt.py` | 58-dimensional MIRT with DAG-based prerequisite graph penalties and soft-constraint propagation |
| **C-Matrix Diagnostics** | `c_matrix.py` | Distractor-level misconception mapping via 15-dimensional z-vectors |
| **SMD-VSNLMS Updater** | `smd_vsnlms.py` | Semantic-weighted parameter updates with entrapment-aware η scaling |
| **KL-CAT Selection** | `kl_cat.py` | Dual-objective item selection with sigmoidal weight decay (Fisher-based, not hard threshold) |
| **Dynamic c_j** | `dynamic_c.py` | Bayesian pseudo-guessing parameter adaptation from E_semantic and empirical response data |
| **Intervention Router** | `intervention_router.py` | Graph-regularized remediation routing to weakest prerequisite |

### Dataset

The item bank is sourced from `data/questions_final_with_E.csv` (548 items × 21 columns) which includes:
- `a_vector`: 58-dimensional Q-matrix discrimination vectors
- `d_param`: difficulty parameters
- `z1`–`z4`: 15-dimensional misconception z-vectors per option
- `E_semantic`: semantic entrapment index per item
- `E_ambiguity`: ambiguity index per item

## Architecture & Core Modules

```
┌─────────────────────────────────────────────────────────────────┐
│                        main.py (CLI)                            │
│  rectify_qmatrix.py → data_processing.py → run_experiment.py    │
└───────────┬─────────────────────────────────────────────────────┘
            │
    ┌───────▼────────────────────────────────────┐
    │           neuronotes/ (Core Engine)         │
    │                                             │
    │  cc_mirt.py ──► kl_cat.py ──► smd_vsnlms.py│
    │       │              │              │       │
    │  concept_graph   c_matrix.py   dynamic_c.py │
    │       │              │                      │
    │       └──────► intervention_router.py       │
    └─────────────────────────────────────────────┘
```

**Data flow per learner per question:**
1. `kl_cat.py` selects the next item (KL divergence + misconception utility + repetition penalty)
2. `cc_mirt.py` computes P(correct) with prerequisite constraints
3. Response is simulated → `c_matrix.py` diagnoses the selected option
4. `smd_vsnlms.py` updates θ (58D) and misconception profile (15D), with η scaled by E_semantic
5. `dynamic_c.py` updates the guessing parameter c_j for the item
6. `intervention_router.py` routes remediation to the weakest prerequisite in the DAG (if applicable)

## Step-by-Step Execution Guide

All experiments run through `main.py`. The pipeline has **4 automated stages**:

### Pipeline Overview

| Step | What Happens | Script |
|:-----|:------------|:-------|
| **1. Rectification** | Fixes z-vectors, injects slip noise, validates Q-matrix integrity | `rectify_qmatrix.py` |
| **2. Data Processing** | Generates `items_clean.csv`, `item_options.csv`, `concept_graph.csv` | `data_processing.py` |
| **3. Experiment** | Runs selected models on synthetic learner pool, computes metrics | `run_experiment.py` |
| **4. Plotting** | Generates comparison charts | `main.py` |

### 1. Quick Start (Default Run)

Runs the full **P7_Full_Neuronotes** model with 200 learners:
```bash
python main.py
```

### 2. Running Experiment Suites

```bash
# Default — P7 only
python main.py --suite final

# Paper comparison (B4 + P7 + all ablations)
python main.py --suite paper

# Full benchmark (all 24 models)
python main.py --suite full
```

### 3. Running Specific Models

```bash
# Compare baseline vs full system
python main.py --models B4_MIRT P7_Full_Neuronotes

# Compare KL selection variants
python main.py --models D4_KL_Only D5_KL_Prereq D6_KL_Misc D7_KL_Full_Pen
```

### 4. Customizing Learner Pool Size

```bash
# Fast smoke test
python main.py --learners 20 --suite paper

# Standard run
python main.py --learners 200 --suite paper
```

### 5. Multi-Seed Statistical Evaluation

```bash
# Specific seeds
python main.py --suite paper --learners 200 --seeds 42 43 44 45 46

# N consecutive seeds from 42
python main.py --suite paper --learners 200 --n-seeds 5
```

### 6. Skipping Data Processing

When iterating on model code only:
```bash
python main.py --skip-data --models B4_MIRT P7_Full_Neuronotes
```
